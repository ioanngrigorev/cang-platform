# Выпуск ассистентом по просьбе владельца

Иван разрешил ассистенту выполнять push и выпуск на production по его команде
5 октября 2026. Повторное ручное подтверждение обычных шагов выпуска не требуется.
Команда вроде «выкати текущие исправления на прод» запускает весь процесс:
проверки → push → CI → резервная копия → деплой → проверка SHA и страниц.
Само изменение кода не является командой публикации.

## Подготовлено на Mac

- Проверена авторизация `gh` и право push для `ioanngrigorev/cang-platform`.
- Репозиторий использует GitHub credential helper через `gh`.
- Проверен `git push --dry-run`; удалённые ветки этим не изменялись.
- Создан отдельный SSH-ключ `~/.ssh/cang_production_ed25519` с закрытыми правами.
- Добавлен SSH-профиль `cang-prod`, проверка ключа хоста включена.
- Приватный SSH-ключ остаётся на Mac; на сервер передаётся только `.pub`.

## Однократная настройка ещё не завершена

На момент подготовки существующие SSH-ключи сервером отвергались. Новый публичный
ключ ещё не установлен на сервере. Вход в панель Vultr в Chrome выполнен.
Управление Terminal через Computer Use заблокировано инструментом; владельцу
передана однократная команда установки ключа:

```bash
ssh-copy-id -i ~/.ssh/cang_production_ed25519.pub cang-prod
```

После установки необходимо проверить `ssh -o BatchMode=yes cang-prod`.
Пароли и токены в чат передавать не требуется.

После получения доступа ассистент должен:

1. Установить и проверить ключ, сохранив действующий доступ владельца.
2. Проверить фактическое состояние VPS, таймера, места на диске и бэкапов.
3. Выполнить однократную миграцию deploy-скриптов из `deploy/README.md`, включая
   резервную копию, пробное восстановление и поиск исторических дублей заказов.
4. Проверить, что таймер использует новый скрипт с ожиданием CI.
5. Обновить этот документ фактическими результатами настройки.

Готовность нельзя объявлять до успешной SSH-проверки. Первый выпуск исправлений
производится по команде владельца; эта настройка сама по себе не подтверждает,
что новый код уже работает на production.
