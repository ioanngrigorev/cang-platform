# Выпуск ассистентом по просьбе владельца

Иван разрешил ассистенту выполнять push и выпуск на production по его команде
5 октября 2026. Повторное ручное подтверждение обычных шагов выпуска не требуется.
Команда вроде «выкати текущие исправления на прод» запускает весь процесс:
проверки → push → CI → резервная копия → деплой → проверка SHA и страниц.
Само изменение кода не является командой публикации.

## Подготовлено на Mac

- Проверена авторизация `gh` и право push для `ioanngrigorev/cang-platform`.
- Репозиторий использует GitHub credential helper через `gh`.
- Проверен `git push --dry-run`; удалённые ветки этим не изменялись.
- Создан отдельный SSH-ключ `~/.ssh/cang_production_ed25519` с закрытыми правами.
- Добавлен SSH-профиль `cang-prod`, проверка ключа хоста включена.
- Приватный SSH-ключ остаётся на Mac; на сервер передаётся только `.pub`.

Обновлены инструменты выпуска. Код приложения на production не обновлялся,
миграции приложения не выполнялись, push в main в ходе настройки не выполнялся.
На следующую явную команду выпуска ассистент выполняет push, следит за CI и деплоем,
проверяет точную версию и здоровье приложения без отдельного ручного шага владельца.

Не повторять первичную установку ключа или bootstrap. Для первого выпуска использовать
подготовленную ветку `codex/production-hardening` после fetch и проверки изменений
remote main; не отправлять старую main поверх новых серверных deploy-скриптов.
Существующая авторизация действует с этого Mac; при её отзыве или работе с другого
компьютера доступ потребуется настроить заново.
