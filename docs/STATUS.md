# CANG (cang.vn) — статус сборки

Обновлено: 2026-09-22 · ветка `master` · `pnpm typecheck` проходит

## Что это

B2B-маркетплейс «Alibaba для вьетнамского производства»: вьетнамские заводы ↔ мировые
закупщики. Next.js 15 + TypeScript + React 19 + Tailwind + PostgreSQL 16 + Drizzle ORM,
модульный монолит, i18n (vi/en, архитектура под zh/ko/ja/ru/th/id).

> **Замена Prisma → Drizzle.** В окружении сборки заблокирован `binaries.prisma.sh`, из-за
> чего Prisma не может выполнить миграции. Схема данных идентична по форме; Drizzle даёт
> чистые TypeScript-миграции и прямой контроль SQL для полнотекстового поиска.
